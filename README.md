# 为什么你的脚本一跑就被封

[English](./README_EN.md) | **中文**

> 写给 AI 时代新手的一份大白话科普。你用 AI 写出了爬虫或者多账号脚本,跑了几次,号没了、IP 被封了、验证码怎么点都点不完。这篇告诉你为什么,以及该怎么办。

不需要你懂技术。能看懂中文就能看懂这篇。

## 先说一个你可能刚经历过的场景

你最近用 AI(比如 Claude、Cursor、各种 agent)写了个脚本。可能是批量抓点数据,可能是管理好几个社交账号自动发东西,也可能是注册一批账号做点什么。

代码 AI 都帮你写好了,一跑,前几次挺顺。然后突然就不行了。

账号被封,或者要求验证,或者 IP 被拉黑,再或者好几个号一起出问题、连着遭殃。你回去问 AI,AI 让你换个 IP、加个延时、挂个代理,你照做了,好一点点,过几天又不行。

这不是你代码写得烂。是你撞上了一堵新手几乎都会撞的墙,叫**反自动化检测**。这篇就讲清楚这堵墙是什么、为什么你绕不过去、以及正确的绕法。

## 平台是怎么发现"这不是真人"的

先破除一个新手最大的误解,你以为平台是靠 IP 认人的,所以换个 IP 就没事了。

不是。平台认你,靠的是三层东西叠在一起。

**第一层,IP 地址。** 这是最表面的一层,也是你唯一知道的那层。同一个 IP 短时间内做很多操作、或者 IP 来自机房(而不是普通家庭宽带),平台会起疑。但这只是最浅的一层,换 IP 只解决了三分之一都不到的问题。

**第二层,浏览器指纹。** 这是新手完全没概念、但恰恰是最要命的一层。

打个比方,如果 IP 是你的"住址",那浏览器指纹就是你的"长相"。你搬了家(换 IP),但长相没变,平台还是一眼认出你。

你的浏览器在访问网站时,会不知不觉暴露一大堆特征,屏幕分辨率、显卡型号、装了哪些字体、时区、语言、Canvas 画图的细微差异等等。这些特征组合起来,几乎是独一无二的,足以标识"你这台设备"。所以哪怕你换了 IP、换了账号,只要还是这台电脑、这个浏览器,平台把这些指纹一比对,就知道"哦,又是这个人"。

**第三层,行为模式。** 真人操作有随机性,鼠标会乱动,看东西有停顿,点击有快有慢。脚本操作太规律,几点几分准时发、间隔一模一样、鼠标直线移动到按钮上,平台一看这个节奏就知道是机器。

这三层是叠加判断的。你只处理了 IP 那一层,另外两层还在裸奔,自然还是被抓。

## 新手最常问的三个"为什么还是被封"

**"我明明换了 IP,为什么还被封?"**

因为你只换了住址,没换长相。浏览器指纹没变,平台照样认得你。换 IP 不换指纹,等于换了个地址但还是同一张脸去,门卫当然还认识你。

**"我用了无痕模式 / 隐身窗口,为什么没用?"**

无痕模式只是不保存你的历史记录和 cookie,它对外暴露的浏览器指纹跟正常模式几乎一模一样。无痕是"你自己看不到痕迹",不是"别人认不出你"。这俩是两回事。

**"我多注册了几个号轮着用,为什么还是被一起封?"**

因为这几个号都在同一个浏览器、同一台设备上登录过。平台通过指纹发现"这几个号背后是同一台设备、同一个人",直接判定为关联账号,一封封一串。你以为的"多个独立账号",在平台眼里是"一个人的好几个马甲"。

## 正确的思路,不是隐藏,是隔离

搞清楚上面的原理,解法方向就清楚了。

你要的不是"把自己藏起来"(藏不住,指纹总会暴露),而是**让每个账号看起来像一个真正独立的、不同的人**。

具体说,每个账号都该有自己独立的一整套身份,独立的浏览器指纹、独立的 cookie、独立的 IP。这样在平台看来,它们就是几个互不相干的真实用户,而不是一个人的几个马甲。这就叫**环境隔离**。

自己手动做这件事非常难(你没法轻易改浏览器指纹)。所以有一类专门的工具叫**指纹浏览器**,它能给你的每个账号分配一个完全独立的浏览器环境,指纹、cookie 各自独立,再各自配一个独立 IP,让账号之间彻底不关联。常见的指纹浏览器有 AdsPower、Multilogin、Dolphin 等等。

如果你想深入了解这个领域的工具、代理选择、指纹检测原理,可以看这份更全的资源整理:

👉 [awesome-anti-detect](https://github.com/pencil20388-eng/awesome-anti-detect)

## 你现在可以做的第一件事

先别急着找工具。先花两分钟,看看你自己现在的浏览器暴露了什么。

打开这个免费网站,[BrowserLeaks](https://browserleaks.com/),它会告诉你,你的浏览器正在向全世界暴露哪些指纹信息,你的 Canvas 指纹、WebGL 显卡信息、时区、字体等等。

看完你就会直观地明白,原来我以为的"匿名",在网站眼里这么清清楚楚。理解了这一点,你就已经比大多数一头撞上封号、还不知道为什么的新手强了。

搞懂了"为什么被封",再去选解法,你才知道自己在解决什么问题,而不是病急乱投医、换个 IP 试一下、挂个代理碰碰运气。

---

**这篇讲的是原理,不是教你去违反任何平台规则。** 正当的多账号运营(比如跨境电商开多个店、做多平台内容分发)是真实存在的需求,理解检测原理是为了合规、稳定地运营,而不是钻空子。任何平台的规则都值得尊重。
